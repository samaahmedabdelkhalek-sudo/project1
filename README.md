## 🕌 Prayer Times

A simple website to display daily prayer times using JavaScript and an API.

---

## ⚡ Project Idea

The website fetches prayer times based on the current date and displays them in a simple way.

---

## 🛠️ Used

- CSS  
- JavaScript  
- API  

---
